# JARVIS by Kewin

Personal AI operating system for Kewin Ngatcheu: one central intelligence with persistent memory, separate business workspaces (NGCX, VenturesX, …), task management and an AI core — built to grow phase by phase without rebuilds.

> **Status: Phase 2 (Personal OS) – working.** See [ROADMAP](docs/ROADMAP.md) for what is built and what is not. Modules that are not built yet are shown as "planned" in the UI – never with fake data.

## Quick start

```bash
npm install
npm run setup        # creates .env.local with a one-time setup token
# optional: put ANTHROPIC_API_KEY=... into .env.local
npm run dev          # http://localhost:3000 → /setup → enter token, choose password
```

No database installation needed for local use: JARVIS runs an **embedded PostgreSQL (PGlite) with pgvector** in `./data/pglite`. For production set `DATABASE_URL` to a PostgreSQL 15+ database with the `vector` extension.

### Configuration (`.env.local`)

| Variable | Purpose |
|---|---|
| `JARVIS_SETUP_TOKEN` | One-time token to create the owner account (generated by `npm run setup`) |
| `ANTHROPIC_API_KEY` / `ANTHROPIC_MODEL` | Claude (default model `claude-opus-5-5`) |
| `OPENAI_API_KEY` / `OPENAI_MODEL` | Optional alternative model |
| `EMBEDDING_PROVIDER` | `local` (offline hashing embedding, default) or `openai` (`text-embedding-3-small`, 256 dims) |
| `DATABASE_URL` | Empty = embedded PGlite. Set for real PostgreSQL + pgvector |
| `JARVIS_SECURE_COOKIES` | `true` when served via HTTPS |

Keys are only read server-side and never sent to the browser.

## Commands

```bash

npm run build      # production build

npm test           # unit + integration tests (in-memory Postgres)
npm run typecheck
BASE_URL=http://localhost:3000 SETUP_TOKEN=... npm run smoke   # browser E2E against a FRESH instance (needs Playwright)
```
